PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open the shree-shyam-properties folder.
3. Double-click index.html to open it in a browser.

PUBLISH FREE (STATIC WEBSITE)
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository, e.g. shree-shyam-properties.
3. Upload all files and the assets folder, keeping the same folder structure.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. Wait for deployment. GitHub Pages will show your live URL in Settings > Pages.

IMPORTANT
- Keep index.html at the repository root.
- External property photos load from Unsplash and Google Fonts require internet access.
- The enquiry form opens WhatsApp with a prefilled message; it does not save form data to a server. The visitor must press Send.
- Property photos are illustrative, not live listings. Replace them with your own photos and confirmed listing details before publishing.
- Check phone, email, address, opening hours, legal details and all claims before publishing.
